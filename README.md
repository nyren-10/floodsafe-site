# Floodsafe overview website

Static, responsive project overview. Open index.html locally or deploy the directory to Vercel with Framework Preset Other and no build command.

The simulation video and live interactive prototype are connected in their respective sections (the simulation video player and the deployed map prototype at https://map-simulation-three.vercel.app/).

Content is based on the supplied project summary and architecture documents. Repository source was inaccessible and is not incorporated. Google Fonts is optional; system sans-serif fonts are the fallback.
